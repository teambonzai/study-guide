# Key Terms & Glossary — 2.3 Biomolecules Overview

Only the words you need for this lesson. Each one has a short, plain meaning.

## Molecules and carbon

| Term | Meaning |
|---|---|
| **Macromolecule** | A big molecule built from smaller pieces. *(OpenStax Biology 2e)* |
| **Monomer** | One small building block. |
| **Polymer** | Many monomers joined together. |
| **Organic / inorganic** | Organic contains carbon. Inorganic does not. |

## Energy and reactions

| Term | Meaning |
|---|---|
| **Energy** | The ability to change or move matter. |
| **Entropy** | Disorder. It always increases. |
| **Chemical reaction** | Bonds break or form, so the chemical becomes something new. |
| **Physical change** | Only the state or size changes. Melting ice is still water. |
| **Reactants / products** | Starting substances on the left. New substances on the right. |
| **Coefficient** | The number in front. It tells how many you need. |
| **Exothermic** | A reaction that releases heat. |
| **Endothermic** | A reaction that absorbs heat. |

## Building, breaking, and ATP

| Term | Meaning |
|---|---|
| **Anabolism** | Building big molecules from small ones. Uses energy. |
| **Catabolism** | Breaking big molecules into small ones. Releases energy. |
| **Dehydration synthesis** | Building molecules by removing water. |
| **Hydrolysis** | Splitting molecules by adding water. |
| **ATP** | The cell's energy currency. It has three phosphates. |
| **ADP** | What's left after ATP loses one phosphate. |

## The four biomolecules

| Term | Meaning |
|---|---|
| **Lipid** | Built from fatty acids and glycerol. Stores long-term energy. |
| **Carbohydrate** | Built from monosaccharides (single sugars). Gives short-term energy. |
| **Protein** | Built from amino acids. Gives structure and forms enzymes. |
| **Nucleic acid** | Built from nucleotides. Stores and carries genetic information. |
| **Enzyme** | A protein that speeds up a reaction. *(OpenStax Biology 2e)* |
| **kcal** | A unit of energy in food. *(OpenStax Biology 2e)* |
